# Smart Bookstore -- Python dependencies
#
# The app runs with NONE of these installed: every optional feature degrades to
# a clear message rather than a crash. Install them in this order of value.
#
#     pip install -r requirements.txt
#
# Tkinter is NOT here because it is not a pip package. If `python run.py` says
# Tkinter is missing:
#     Ubuntu/Debian : sudo apt install python3-tk
#     Fedora        : sudo dnf install python3-tkinter
#     macOS (brew)  : brew install python-tk
#     Windows       : reinstall Python with the "tcl/tk and IDLE" option ticked

# --- Needed for picture search, Shelf Scan and cover thumbnails -------------
numpy>=1.24
Pillow>=10.0

# --- Needed for face login (detection) and camera capture ------------------
# OpenCV 5 dropped the contrib `face` module, so the project trains its own
# eigenface classifier in numpy and uses OpenCV only for detection and camera
# access. Either 4.x or 5.x works.
opencv-python>=4.8

# --- Needed for the web client and the REST API ----------------------------
# `python run.py` (the Tkinter desktop client) does not use these. They are
# needed by `python -m bookstore.api`, which serves the same business rules
# over HTTP and hosts the browser client in web/.
fastapi>=0.110
uvicorn[standard]>=0.27
httpx>=0.27            # also what tests/test_api.py drives the API with

# --- Optional: microphone recording for voice enrolment --------------------
# Without it, voice enrolment and login still work from saved .wav files.
sounddevice>=0.4

# --- Optional: YOLO face detection and YOLO shelf segmentation -------------
# The spec asks for a "yolo-based procedure". With ultralytics installed and
# the weights fetched (python tools/fetch_models.py --yolo), detection uses
# YOLO. Without it, the app falls back to OpenCV's YuNet DNN detector, then to
# a Haar cascade, then to a centre crop -- in that order, and it tells you
# which one it picked.
# ultralytics>=8.0

# --- Not a pip install -----------------------------------------------------
# The chat box's LLM fallback talks to Ollama over plain HTTP using only the
# standard library. Install Ollama from https://ollama.com, then:
#     ollama serve
#     ollama pull llama3.2
# Without it, RAG answers from local files still work; only the
# general-knowledge fallback is unavailable, and the app says so.
