# Open Shelf -- Python dependencies
#
#     pip install -r requirements.txt
#
# Everything below is needed. The optional-extras era ended when the project
# moved from text files to a database and from a desktop window to a browser:
# there is no longer a meaningful subset that runs.

# --- The service -----------------------------------------------------------
fastapi>=0.110
uvicorn[standard]>=0.27
pydantic>=2.6

# FastAPI needs this to parse multipart/form-data, which is how every upload
# in this project arrives: the camera frames, the cover-search image and the
# Shelf Scan photograph. Nothing here imports it by name -- FastAPI reaches
# for it when it builds a route that declares File() or Form(), and raises at
# import time if it is absent. That is why it was missed: a search of this
# codebase for "multipart" finds nothing, and the machine it was developed on
# already had it. The app will not start without it.
python-multipart>=0.0.9

# --- The database ----------------------------------------------------------
# SQLAlchemy targets the session, not a dialect, so the same code runs on
# PostgreSQL (the default), MySQL and SQLite. DATABASE_URL picks one.
SQLAlchemy>=2.0
alembic>=1.13
psycopg[binary]>=3.1        # the PostgreSQL driver
# PyMySQL>=1.1              # uncomment for MySQL

# --- Authentication --------------------------------------------------------
python-jose[cryptography]>=3.3   # signs and verifies the access tokens

# --- Images, recognition and search ----------------------------------------
# numpy does the real work: the eigenface classifier and the image
# descriptor are implemented here rather than imported. OpenCV is used only
# for face *detection*, because OpenCV 5 removed the contrib `face` module
# entirely.
numpy>=1.24
Pillow>=10.0
opencv-python>=4.8

# --- Tests -----------------------------------------------------------------
# pytest is not needed to run the site, only to check it.
pytest>=8.0
httpx>=0.27                 # what TestClient drives the API with

# --- Optional: YOLO face detection and shelf segmentation -------------------
# The specification asks for a "yolo-based procedure". With ultralytics
# installed and the weights fetched (python tools/fetch_models.py --yolo),
# detection uses YOLO. Without it, detection falls back to OpenCV's YuNet DNN,
# then a Haar cascade, then a centre crop -- and says which one it chose.
# ultralytics>=8.0

# --- Not a pip install -----------------------------------------------------
# The assistant's general-knowledge fallback talks to Ollama over plain HTTP
# using only the standard library. Install Ollama from https://ollama.com:
#     ollama serve
#     ollama pull llama3.2
# Without it, questions about the site are still answered from local files;
# only general questions are unavailable, and the app says so.
